## 3. Font Faces & Loading

- **Inter** (headings + body): neutral, highly legible at small sizes, excellent for dense UI and long-form reading; variable weight keeps one file. Fits a minimal aesthetic without personality competing with content.
- **JetBrains Mono**: clear distinction between `0/O`, `1/l/I`, good ligature-free default for code answers.

**Fallback stacks**
```css
--font-heading: "Inter Variable", "Inter", ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
--font-body:    "Inter Variable", "Inter", ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
--font-mono:    "JetBrains Mono Variable", "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, Consolas, "Liberation Mono", monospace;
```

**Loading strategy:** `font-display: swap` — text renders immediately in the fallback and swaps when loaded; acceptable because Inter and system-ui have similar metrics. Preload the Inter Latin subset only.

**Source:** self-hosted via npm (`@fontsource-variable/inter`, `@fontsource-variable/jetbrains-mono`):
```ts
// frontend/src/main.tsx
import "@fontsource-variable/inter";
import "@fontsource-variable/jetbrains-mono";
```

**Self-hosting trade-offs:** no third-party requests (privacy, CSP stays `font-src 'self'`), fonts cached with immutable hashed URLs by Vite; cost is ~100 KB in our bundle output and manual version bumps via Dependabot.

### 4b. Tailwind 4 `@theme` (CSS-first config)

Tailwind 4 has no `tailwind.config.ts`; the theme is declared in CSS. Tokens that belong to a Tailwind namespace (`--color-*`, `--font-*`, `--text-*`, `--radius-*`, `--shadow-*`, `--container-*`) are declared **once**, in `@theme`, with their light values — Tailwind emits them as `:root` custom properties and generates utilities (`bg-primary`, `text-fg-muted`, `font-mono`, `text-h1`, `rounded-lg`, `shadow-focus`, `max-w-chat`). The `[data-theme="dark"]` overrides and the non-utility tokens (`--space-*`, `--focus-ring`, `--sidebar-width`) stay in plain CSS in `tokens.css`, exactly as in 4a. Spacing utilities use Tailwind's default `--spacing: 0.25rem`, which is the same 4px grid.

