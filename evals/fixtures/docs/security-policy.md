# Information Security Policy (version 4.2)

## Passwords

Passwords must have at least 14 characters. Password managers are mandatory. Passwords are rotated only after a suspected compromise, not on a fixed schedule.

## Multi-factor authentication

MFA is required for email, the VPN and the admin console. Hardware security keys are required for production access. SMS codes are not accepted as a second factor.

## Data classification

Data is classified as Public, Internal, Confidential or Restricted. Customer personal data is Restricted and must never be copied to personal devices.

## Incident reporting

Report suspected security incidents to security@lumenlabs.example within 1 hour of discovery. The security team acknowledges within 30 minutes during business hours. A post-incident review is held within 5 working days.

## Devices

All laptops use full-disk encryption. Lost devices must be reported immediately so that they can be wiped remotely. Software may only be installed from the approved catalogue.
